# **🧠 Arth Intelligence Engine**

### **🤖 Meaning-Centric AI Translation for indian languages. 🤖**

---

## **📌 Overview**

> **The  Arth Intelligence Engine is an `AI-powered language understanding system` designed to go beyond literal translation.**

- **It focuses on `meaning, emotion, cultural context, and spiritual depth`, especially for Indian languages.**
- **The project uses a `Large Language Model (Gemini)` with advanced `prompt engineering` to interpret poetry, idioms, mantras, mixed language inputs, and regional variations.**

---

## **🎯 Objectives**

- **Provide `meaning-aware translation` instead of word-by-word conversion**
- **Handle `Indian cultural idioms and expressions`**
- **Support `contextual tone transformation`**
- **Interpret `Sanskrit mantras (Mantra Arth)`**
- **Deliver `simple, human-readable explanations`**

---

## **🚀 Key Features**

### **1️⃣ Cultural Idioms Translator**

- **Detects Hindi/Gujarati idioms inside full sentence.**
- **Translates actual meaning, not literal words.**

### **2️⃣ Context-Aware Translation**

- **Transforms text based on `selected style`**
  - *`Casual`*
  - *`Formal`*
  - *`Romantic`*
  - *`Inspirational`*
  - *`Super Friendly`*
  - *`Angry`*
  - *`Funny`*

### **3️⃣ Mixed Language Translation**

- **Supports Hinglish/Gujlish like mixed script input.**
- **Automatically detects intent and meaning.**

### **4️⃣ Local Language Variations**

- **Supports regional forms like:**
- **In `Gujarati`**
  - *Standard Gujarati*
  - *Surati*
  - *Kathiyawadi*
  - *Charotari*
  - *Ahmedabad urban*
  - *Kutchi gujarati* 
- **In `Hindi`**
  - *Mumbai tapori hindi*
  - *UP/Awadhi hindi*
  - *Bhojpuri*
  - *Haryanvi*
  - *Rajasthani/Marwari*
  - *Bundelkhandi*
- **In `English`**
  - *Standard Formal English*
  - *Casual English*
  - *Business English*
  - *American English*
  - *British English*
  - *Hinglish*
  - *Gujlish*
  - *Tapori English*

### **5️⃣ Mantra Arth (Sanskrit Interpretation)**

- **Accepts mantra in `Sanskrit` language**
- **Provides**
  - *Word-to-word explnation.*
  - *Simple hearfelt explanation.*
  - *Daily life / Spiritual benefits.*

## **⚙️ How It Works**

1. **User enters text (poem, mantra, sentence, or mixed language)**
2. **System detects language, intent, and cultural context**
3. **Carefully designed prompts guide the LLM**
4. **Output is generated in `structured JSON`**
5. **Frontend renders results in a clean UI**
